# GUARDIA 🛡️
> Smart Accident Detection & SOS App

## Setup
1. Clone repo: `git clone https://github.com/YOUR_USERNAME/guardia`
2. Install deps: `npm install`
3. Add `.env`:
   EXPO_PUBLIC_GOOGLE_MAPS_API_KEY=your_key
   EXPO_PUBLIC_FIREBASE_API_KEY=your_key
   EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=...
   EXPO_PUBLIC_FIREBASE_PROJECT_ID=...
4. Run: `npx expo start`

## Features
- Auto crash detection via accelerometer
- Instant SOS with SMS + GPS link
- Live location sharing with contacts
- Google Maps live tracking
- Incident history + reports
- Guardian mode for families

## Stack
React Native · Expo · Firebase · Google Maps · Zustand · Reanimated 3
